Python 3 с `pypdf` (в песочнице потребовалась установка `cffi`). Режим сервера проверяется в настоящем браузере против настоящего
сервера на провайдере-заглушке: мастер резюме → сервер → вакансия → сопоставление из
вставленного текста → вопросы → автосохранение ответов → перезагрузка страницы →
интервью потоком → итог → карточка → разбор вставленного резюме → устаревание и пересборка.
Ни один набор не выходит в сеть. Разбор изменений по итерациям — в `docs/iterations.md`. Сторонних сетевых запросов нет ни в одном наборе, ошибок в консоли
браузера нет. Скриншоты — в `docs/screenshots/`.

## Часть 3. Программа для компьютера

Запускалось настоящее приложение Electron под Xvfb (Linux, без графической оболочки).

| Группа | Проверки | Результат |
| --- | --- | --- |
| Экран согласия | Показан при первом запуске; кнопка заблокирована до трёх отметок; двух отметок недостаточно; есть предупреждение о согласовании с работодателем и о видимости окна при демонстрации | 6 из 6 |
| Настройки | Панель открывается; провайдер и режим чтения по умолчанию — заглушка; сказано, что ключ не пишется на диск | 4 из 4 |
| Ключ доступа | Файл настроек создан; ключа в нём нет; согласие сохранено; ключа нет ни в одном файле профиля | 4 из 4 |
| Источники захвата | Список получен; тестовый источник помечен; запуск заблокирован до выбора; разрешён после выбора | 4 из 4 |
| Цикл сессии | Кадр снят; подсказка получена; помечена как заглушка | 3 из 3 |
| Прозрачное окно | Открыто; показано направление ответа; есть напоминание о видимости; фон действительно прозрачный (`rgba(0, 0, 0, 0)`) | 4 из 4 |
| Остановка и следы | Сессия остановлена; кадры на диск не сохранены | 2 из 2 |

Цикл проходил на провайдере-заглушке: кадр → выделение вопроса → подсказка → показ в окне.
Два запроса к слою модели на один кадр, сеть не использовалась.

**Ограничение среды.** Настоящий захват экрана в окружении без графической оболочки
недоступен: система не возвращает ни одного источника. Цикл проверялся на тестовом
источнике (`ASSISTANT_FAKE_CAPTURE=1`), который помечен в интерфейсе и по умолчанию
выключен. Захват настоящего экрана на живой системе не проверялся.

## Что НЕ проверено

- Реальные браузеры кроме Chromium: Firefox и Safari не запускались, в том числе на
  настоящих мобильных устройствах. Проверялся эмулированный мобильный размер экрана.
- **Настоящий захват экрана.** В среде проверки источники недоступны, использовался
  тестовый источник. Поведение на живой системе с выдачей разрешения на запись экрана
  не проверялось.
- **Программа для компьютера на macOS и Windows.** Запускалась только на Linux.
  Прозрачность окна и поведение «поверх всех окон» на других системах различаются.
- **Реальные запросы к сервисам моделей.** Все проверки шли на провайдере-заглушке:
  ключи не подключались, деньги не тратились. Адаптеры Anthropic, OpenAI и Gemini
  проверены только на форме собираемого запроса, а не на живом ответе сервиса.
- **Точность подсказок.** Качество ответов модели не оценивалось: для этого нужен
  отдельный набор примеров и живой сервис.
- Скринридеры (NVDA, VoiceOver) вручную не проверялись. Сделаны семантическая разметка,
  подписи полей, `aria`-атрибуты, видимый фокус и ловушка фокуса в диалогах, но реального
  прослушивания не было.
- Автоматическая проверка контраста по WCAG не выполнялась: палитра подбиралась вручную.
- Печать и экспорт не проверялись — их в макете нет.
- Поведение при отключённом JavaScript: показывается только текстовое сообщение `noscript`.
- Нагрузочные и кроссплатформенные проверки не проводились: продуктового кода нет.
