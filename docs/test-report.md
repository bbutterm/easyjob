## Что НЕ проверено

- Реальные браузеры кроме Chromium: Firefox и Safari не запускались, в том числе на
  настоящих мобильных устройствах. Проверялся эмулированный мобильный размер экрана.
- Скринридеры (NVDA, VoiceOver) вручную не проверялись. Сделаны семантическая разметка,
  подписи полей, `aria`-атрибуты, видимый фокус и ловушка фокуса в диалогах, но реального
  прослушивания не было.
- Автоматическая проверка контраста по WCAG не выполнялась: палитра подбиралась вручную.
- Печать и экспорт не проверялись — их в макете нет.
- Поведение при отключённом JavaScript: показывается только текстовое сообщение `noscript`.
- Нагрузочные и кроссплатформенные проверки не проводились: продуктового кода нет.
