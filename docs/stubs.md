# Перечень заглушек

Каждое действие ниже намеренно не выполняет реальную работу. Везде показано понятное
объяснение — молчаливых no-op кнопок в макете нет.

| Место | Действие | Что происходит | Чего не происходит |
| --- | --- | --- | --- |
| `#/auth/*` | Вход, регистрация, восстановление | Визуальная форма с предупреждением | Данные не проверяются, аккаунт не создаётся, письма не отправляются, пароль не запрашивается |
| Мастер резюме | «Собрать резюме» | Короткое демонстрационное ожидание, затем предпросмотр из введённых полей | ИИ не вызывается, текст не переписывается; блок «Образец формулировки» помечен как фиксированный пример |
| Мастер резюме, карточка резюме | «Экспорт в PDF» | Диалог «Экспорт не реализован» | Файл не создаётся и не скачивается |
| `#/resume/upload` | Выбор или перетаскивание файла | Показывается имя файла, его можно заменить или удалить | Файл не читается, не разбирается и не отправляется на сервер |
| `#/resume/upload` | «Показать пример анализа» | Открывается образец отчёта на подготовленном резюме | Это не разбор вашего файла; ложные работодатели и достижения не добавляются |
| `#/resume/upload` | «Принять» / «Отклонить» предложение | Меняется демонстрационная версия и её предпросмотр | Ваше настоящее резюме не изменяется |
| `#/vacancy/new` | «Импортировать по ссылке» | Диалог с объяснением и предложением вставить текст | Сетевой запрос к сайту вакансий не выполняется |
| `#/prep/*/match` | Отчёт сопоставления | Требования, подтверждения и рекомендации из комплекта демо | Введённый текст вакансии не анализируется; общий процент соответствия не показывается |
| `#/prep/*/questions` | Ответы и отметки «Подготовлено» | Сохраняются в памяти страницы | Ответы не оцениваются, после перезагрузки сбрасываются |
| `#/prep/*/interview` | Отправка ответа | Ответ виден в переписке, следующая реплика берётся из сценария | Ответ не оценивается ИИ |
| `#/prep/*/interview` | «Показать ошибку отправки (демо)» | Демонстрация состояния ошибки и повтора | Настоящего сбоя нет |
| `#/prep/*/interview` | Итоговый отчёт | Заранее подготовленный текст | Не составлен по вашим ответам |
| `#/prep/*/voice` | Все кнопки голосового экрана | Переключение состояний и расшифровка из сценария | Микрофон не запрашивается, звук не записывается, синтеза речи нет |
| `#/prep/*/voice` | «Микрофон (заглушка)» | Диалог с объяснением | Разрешение на микрофон не запрашивается |
| `#/assistant` | «Скачать помощник» | Диалог «Компонент ещё не доступен» | Никакой файл не скачивается — ни пустой, ни фиктивный, ни исполняемый |
| `#/assistant` | «Подключить», кнопки статусов | Демонстрационные статусы «Не подключён», «Подключение», «Подключён», «Ошибка подключения», «Сессия завершена» | Сетевого соединения нет |
| `#/assistant` | «Посмотреть пример подсказок» | Панель с заранее подготовленными репликами; примеры переключаются, панель сворачивается и закрывается | Звук и экран не считываются, подсказки не генерируются |
| `#/plans` | «Оплатить» | Диалог «Оплата недоступна» | Нет банковских полей, платёжных SDK и списаний |
| `#/plans`, панель демо | Переключение демо-уровня | Меняется доступность разделов, заблокированные объясняются | Покупка невозможна: тарифы и лимиты не утверждены |
| `#/settings` | «Сохранить профиль» | Уведомление, что данные не сохраняются | Персональные данные не хранятся |
| `#/settings` | Переключатели уведомлений | Локальное состояние UI | Письма и push-уведомления не отправляются |
| `#/settings` | «Удалить ответы», «Очистить историю», «Сбросить демо» | Подтверждение и очистка данных сеанса | Серверных данных нет — очищается только память вкладки |

## Нерешённые вопросы, которые макет не выдаёт за готовые решения

- Формат скачиваемого помощника, поддерживаемые операционные системы, способ установки,
  обновления и протокол соединения.
- Исходное пожелание о «невидимом окне» помощника: макет не обещает незаметность при
  демонстрации экрана или для собеседника. Это открытый технический и правовой вопрос.
- Названия, состав и цены тарифов; объёмы лимитов.
- Юридические формулировки о хранении и обработке персональных данных.
- Поддержка чтения PDF и DOCX и получение вакансий по ссылке.
