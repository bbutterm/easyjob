Резюме и вакансия по ссылке hh.ru

Сервер открывает страницу в собственном браузере, без ваших куки. Всё показывается для проверки и сохраняется только после подтверждения.

Вакансия по ссылке

Название, компания, зарплата, описание и ключевые навыки подставляются в форму. Если разметка сайта не распозналась, модель выделяет вакансию из текста страницы.

Резюме по ссылке

Публичное резюме раскладывается по полям: должность, опыт с компаниями и периодами, навыки, образование. Закрытые резюме и капча не обходятся.

Поиск подходящих

Запрос собирается из профессии и навыков, выдача сортируется по похожести на резюме с пояснением «совпало: …». Одна кнопка переносит вакансию в подготовку.

Тренировочное интервью

Интервьюер задаёт по одному вопросу, помнит сказанное и не повторяет темы. Обратная связь без баллов: что сильно, чего не хватает, как переформулировать.

Голосовая тренировка

реплики озвучиваются по фразам
Расскажите о смене, когда на кухне что-то пошло не так. Что вы сделали первым?
Сломалась плита в пятницу вечером. Перекинул заказы на гриль и пароконвектомат, предупредил зал о задержке.
Сколько столов вы тогда обслужили без плиты?

Ответ распознаётся с микрофона, интервьюера можно перебить. Синтез речи в браузере или на сервере.

Память интервью

Факты из ваших реплик фиксируются с цитатой и статусом: сказано, есть в резюме, подтверждено, противоречит. Длинное интервью сжимается без потери фактов.

Честность по умолчанию

Модель не добавляет опыт, которого нет в резюме, и говорит, чего ей не хватает, вместо догадки.

Карточка перед встречей

Короткая шпаргалка из ваших же ответов: с чего начать, сильные стороны, рискованные темы, что спросить у них.

Помощник на живом собеседовании

Подсказка как опора для своего ответа, а не текст для зачитывания. Только с явного согласия: захват экрана включается вручную, текст экрана нигде не хранится.

Видит вопрос

Из текста на экране видеозвонка модель выделяет вопрос собеседующего и только тогда просит подсказку. До 40 слов, чтобы читалось в разговоре.

Программа для компьютера

Прозрачное окно поверх звонка. Прототип на Electron лежит в репозитории и запускается из исходников.

Каждый ответ подписан источником: провайдер, модель, этап. Заглушки всегда помечены как заглушки.

Доверие и стоимость

Открытые модели

Продуктовые задачи идут только на модели с открытыми весами. Подготовка и живое интервью настраиваются на разные модели: быстрая там, где важна скорость.

Ключи на сервере

Браузер и программа не знают ключей. Запросы ограничены по размеру: если резюме не помещается, будет честная ошибка, а не платный вызов.

Расход по этапам

Каждый вызов модели учтён: задача, этап, токены, стоимость, повторы. Владелец видит сводку за 30 дней.

Данные пользователя

Аккаунт, свои резюме и подготовки, удаление всех данных одной кнопкой. Наружу уходит только нужное задаче и только с согласия.

Проверено

Более 600 автоматических проверок: сервер, браузерные сценарии, импорт, голос, hh.ru, программа для компьютера. Ни одна не выходит в сеть.

Простой запуск

Node 22 и SQLite, один процесс, без внешних сервисов. Распознавание и синтез речи можно поднять рядом на своём сервере.

Как запустить

Рабочий прототип. Живые модели подключаются ключом провайдера на сервере; без ключа работает заглушка, и это видно на каждом экране.

npm ci && npx playwright install --with-deps chromium
cp .env.example .env    # ключ провайдера и маршруты моделей
npm start               # http://localhost:8080
