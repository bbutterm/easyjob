Резюме и вакансия

Ссылка на hh.ru вместо копипасты

  • Вакансия по ссылке. Сервер открывает страницу в собственном браузере, без ваших куки. Название, компания, зарплата, описание и ключевые навыки подставляются в форму для проверки.
  • Резюме по ссылке. Публичное резюме hh.ru раскладывается по полям: должность, опыт с компаниями и периодами, навыки, образование. Сохраняется только после вашего подтверждения.
  • Поиск подходящих вакансий. Запрос собирается из профессии и навыков, выдача сортируется по похожести на резюме с объяснением «совпало: …». Кнопка «Создать подготовку» переносит вакансию в работу.
  • Модель читает страницу, а не регулярка. Если разметка сайта не распозналась, модель выделяет саму вакансию из текста страницы, отбрасывая меню и «похожие вакансии».

Интервьюер, который помнит, что вы сказали

  • Текстом и голосом. Реплики интервьюера озвучиваются по фразам, ответ распознаётся с микрофона, можно перебить. Синтез в браузере или на сервере.
  • Память интервью. Факты из ваших реплик фиксируются с цитатой и статусом: сказано, есть в резюме, подтверждено, противоречит. Длинное интервью сжимается без потери фактов.
  • Обратная связь без баллов. По каждому ответу: что сильно, чего не хватает, как переформулировать. Итог интервью и карточка-шпаргалка перед встречей.
  • Честность по умолчанию. Модель не добавляет опыт, которого нет в резюме, и говорит, чего ей не хватает, вместо догадки.

Живое собеседование

Подсказка — опора для своего ответа, не текст для зачитывания

  • Видит вопрос. Текст с экрана видеозвонка распознаётся, модель выделяет вопрос собеседующего и только тогда просит подсказку.
  • Отвечает по вашему резюме. Направление, о чём напомнить и чего избегать, до 40 слов, чтобы читалось в разговоре.
  • Только с явного согласия. Захват экрана включается вручную, кадр в веб-версии не отправляется, текст экрана нигде не хранится.
  • Программа для компьютера. Прозрачное окно поверх звонка, готовый прототип на Electron в репозитории.

Доверие и стоимость

Построено так, чтобы владелец видел расходы, а пользователь — свои данные

Открытые модели

Продуктовые задачи идут только на модели с открытыми весами через совместимые API. Маршрут «подготовка» и «живое интервью» настраиваются отдельно: дешёвая и быстрая модель там, где важна скорость.

Ключи на сервере

Браузер и программа для компьютера не знают ключей. Каждый запрос ограничен по размеру: исходный текст резюме никогда не выбрасывается молча, а не помещается — честная ошибка вместо платного вызова.

Расход по этапам

Каждый вызов модели учтён: задача, этап, токены, стоимость, повторы. Владелец видит сводку за 30 дней в разделе «Расходы AI».

Данные пользователя

Аккаунт, свои резюме и подготовки, удаление всех данных одной кнопкой. Наружу уходит только то, что нужно задаче, и только с согласия.

Проверено

Более 600 автоматических проверок: сервер, браузерные сценарии, импорт, голос, hh.ru, программа для компьютера. Ни одна не выходит в сеть.

Простой запуск

Node 22 и SQLite, один процесс, без внешних сервисов. Распознавание и синтез речи можно поднять рядом на своём сервере.
