# Импорт вакансии по ссылке

Маршрут `POST /api/vacancies/import-url` с телом `{ "url": "https://…" }`. Сервер читает
публичную страницу сам, без куки и заголовков пользователя, и возвращает предпросмотр:

```json
{ "ok": true, "vacancy": { "sourceUrl": "…", "title": "…", "company": "…", "rawText": "…",
  "source": "jsonld|meta|html|text", "retrievedAt": 1700000000000, "needsReview": false, "truncated": false } }
```

Текст показывается пользователю на экране «Добавление вакансии», где он правит заголовок,
компанию и текст. В разбор требований (`vacancy.parse`) уходит только то, что пользователь
подтвердил кнопкой «Создать подготовку» (`POST /api/vacancies` с `sourceUrl`, `source`,
`retrievedAt`). Вакансия хранит адрес без параметров-токенов, способ получения и время.

## Ошибки

Ожидаемый отказ импорта приходит с кодом 200 и телом `{ "ok": false, "code": "…", "error": "понятное сообщение" }` (в скобках — статус, который несёт `HttpError` внутри сервера):

| Код | Когда | Что делать пользователю |
| --- | --- | --- |
| `private_url` (400) | не http(s), логин в адресе, localhost, внутренний или облачный адрес, нестандартный порт, переход на такой адрес | вставить текст вручную |
| `unsupported_site` | имя не разрешается, не HTML, соединение не установилось, некорректный переход | проверить ссылку, вставить текст |
| `blocked` | 401, 403, 429, 503 или больше трёх переходов: сайт не разрешил автоматическое чтение | вставить текст вручную |
| `not_job_page` | 404, 410 | проверить ссылку |
| `empty_content` | текста меньше 120 знаков: страница рисуется скриптом | вставить текст вручную |
| `too_large` | больше 2 МБ до или после распаковки | вставить текст вручную |
| `timeout` (504) | весь запрос дольше 12 секунд, включая чтение тела | повторить или вставить текст |

Примеры вакансий как «успешный импорт» не показываются никогда.

## Границы безопасности (SSRF)

- Только `http:` и `https:`; адрес с логином и паролем отклоняется; порты только 80 и 443.
- Имена `localhost`, `*.localhost`, `*.local`, `*.internal`, `*.home.arpa` и имена без точки отклоняются.
- Имя разрешается заранее (`dns.lookup`, все адреса); если хотя бы один адрес частный,
  отказ. Частные: 0/8, 10/8, 127/8, 100.64/10, 169.254/16, 172.16/12, 192.168/16, 192.0.0/24,
  192.0.2/24, 198.18/15, 198.51.100/24, 203.0.113/24, 224/3; IPv6 `::`, `::1`, `fc00::/7`,
  `fe80::/10`, `ff00::/8`, `2001:db8::/32`, IPv4 внутри IPv6 (`::ffff:`, `64:ff9b::`).
- Соединение идёт на проверенный адрес: параметр `lookup` HTTP-клиента закреплён, повторное
  разрешение имени между проверкой и соединением невозможно (защита от DNS rebinding).
- Не больше трёх переходов; каждый адрес перехода проходит те же проверки.
- Предел времени 12 с на весь запрос, включая чтение тела; предел 2 МБ на тело и на результат
  распаковки gzip/deflate.
- Принимаются только `text/html`, `application/xhtml+xml`, `text/plain`.
- Скрипты не выполняются: JSON-LD читается как данные, разметка превращается в текст,
  `script`, `style`, `nav`, `header`, `footer`, `aside`, `form` отбрасываются.
- В журнал не попадают ни текст страницы, ни адрес с параметрами.
- Частный адрес разрешён только явному списку `URL_IMPORT_ALLOW_HOSTS=хост:порт,…`
  (проверки и разработка); флага «разрешить всё» нет.

## Разбор страницы

1. JSON-LD `JobPosting` (в том числе внутри `@graph`): title, hiringOrganization, description,
   responsibilities, qualifications, skills, experienceRequirements, educationRequirements,
   employmentType, baseSalary, jobLocation. `needsReview: false`.
2. Иначе `og:title` / `h1` / `<title>` (первая часть до « — », « | », « - »), `og:site_name`
   или хост как компания, текст `<main>` или `<article>`, иначе всей страницы без навигации.
   `needsReview: true` — пользователю предлагается проверить текст.
3. Адаптеров под конкретные площадки нет. CAPTCHA, вход, платный доступ и антибот-системы не
   обходятся: такой сайт даёт `blocked`, и пользователь вставляет текст вручную.

## Проверки

`npm run test:import` — 67 проверок без сети: частные адреса, отклоняемые ссылки, явный
список хостов, вырезание токенов, разбор JSON-LD/мета/HTML, локальный сайт с переходами
(в том числе на внутренний адрес и loopback), 403, 404, не HTML, размер, распаковка, время,
незавершающееся тело. В `tests/server.test.js` — маршрут и правка/удаление вакансии, в
`tests/live.test.js` — сценарий в браузере с отказом сайта и успешным импортом.
