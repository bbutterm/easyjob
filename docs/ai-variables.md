# Переменные для запросов к модели

> Файл сгенерирован из `shared/ai/variables.js`, `shared/ai/capabilities.js` и
> `shared/ai/request.js` командой `node tools/gen-ai-docs.js`. Руками не править —
> правьте исходники и перегенерируйте.

Всего переменных: **53**, из них с персональными данными: **16**. Задач: **11**. Провайдеров: **7**.

## Группы переменных

### Среда выполнения (`runtime`)

Не отправляется в модель как текст — управляет тем, как собран запрос.

| Переменная | Тип | Обяз. | ПДн | Источник | Объём | Пояснение |
| --- | --- | --- | --- | --- | --- | --- |
| `runtime.provider` | enum | да | нет | настройки сервиса | — | anthropic \| openai \| gemini \| openai_compatible \| mock. Определяет адаптер. |
| `runtime.model` | string | да | нет | настройки сервиса | — | Идентификатор модели у выбранного провайдера. |
| `runtime.locale` | string | да | нет | настройки пользователя | — | Язык ответа. По умолчанию ru-RU. |
| `runtime.maxOutputTokens` | number | да | нет | настройки задачи | — | Ограничение длины ответа. У задач разное: подсказка короткая, разбор резюме длинный. |
| `runtime.contextBudget` | number | да | нет | настройки задачи | — | Бюджет входного контекста в токенах. По нему усекаются слои контекста. |
| `runtime.streaming` | enum | нет | нет | настройки задачи | — | on \| off. Для подсказок на живом интервью нужен потоковый вывод. |

### Ограничения и правила ответа (`policy`)

Собирается в системную инструкцию. Одинаково для всех провайдеров по смыслу, по способу передачи — различается (см. capabilities.js).

| Переменная | Тип | Обяз. | ПДн | Источник | Объём | Пояснение |
| --- | --- | --- | --- | --- | --- | --- |
| `policy.language` | string | да | нет | runtime.locale | мал | Язык, на котором модель обязана отвечать. |
| `policy.noInvention` | string | да | нет | константа продукта | мал | Запрет придумывать работодателей, достижения, цифры и сертификаты за пользователя. |
| `policy.tone` | enum | нет | нет | настройки пользователя | мал | neutral \| supportive \| direct. Влияет на формулировки, не на содержание. |
| `policy.outputFormat` | enum | да | нет | настройки задачи | мал | json \| text. Для json адаптер включает режим структурированного вывода, если провайдер его умеет. |
| `policy.maxWords` | number | нет | нет | настройки задачи | мал | Жёсткий предел длины. Для подсказки на живом интервью — около 40 слов. |
| `policy.disclaimer` | string | нет | нет | константа продукта | мал | Требование не обещать трудоустройство и не выдавать оценку за гарантию. |

| `user.city` | string | нет | **да** | профиль | мал | Город. Влияет на формат работы и переезд. |

Продукт не ограничен списком профессий: если профессии нет в справочнике, в модель уходит название, введённое пользователем, и признак isKnown=false.

| --- | --- | --- | --- | --- | --- | --- |

| `profession.id` | string | нет | нет | справочник | — | Идентификатор, если профессия найдена в справочнике. Пусто для произвольной. |

| `profession.seniority` | enum | нет | нет | резюме или вакансия | мал | junior \| middle \| senior \| lead. Влияет на глубину вопросов. |

## Задачи

Для каждой задачи указано, какие переменные она использует, что возвращает и какие
ограничения заданы по умолчанию в `shared/ai/request.js`.

### `resume.draft` — Собрать резюме из ответов мастера

- **Переменные:** `policy.*`, `profession.name`, `profession.isKnown`, `user.displayName`, `user.preferences`, `resume.experience`, `resume.skills`, `resume.achievements`, `resume.education`
- **Формат ответа:** json — `{ summary: string, experience: [{role, company, period, details}], skills: string[], suggestions: string[] }`
- **По умолчанию:** длина ответа 4000 токенов, бюджет контекста 24000 токенов, потоковый вывод: нет
- **Правило:** Модель переписывает формулировки пользователя, но не добавляет новых мест работы, достижений и цифр. Всё добавленное должно попадать в suggestions как предложение, а не в текст.

### `resume.review` — Разбор готового резюме

- **Переменные:** `policy.*`, `profession.name`, `resume.*`, `vacancy.title`
- **Формат ответа:** json — `{ strengths: string[], vague: [{title, before, after, why}], missing: [{title, after, why}] }`
- **По умолчанию:** длина ответа 4000 токенов, бюджет контекста 32000 токенов, потоковый вывод: нет
- **Правило:** Поле before обязано быть дословной цитатой из резюме. Если цитаты нет — предложение относится к missing, а не к vague.

### `vacancy.parse` — Извлечь требования из текста вакансии

- **Переменные:** `policy.*`, `vacancy.title`, `vacancy.rawText`
- **Формат ответа:** json — `{ requirements: [{id, text, kind: hard\|soft\|formal, weight: 1..3}] }`
- **По умолчанию:** длина ответа 2000 токенов, бюджет контекста 24000 токенов, потоковый вывод: нет
- **Правило:** Только то, что есть в тексте. Требования не додумываются по названию должности.

### `match.requirements` — Сопоставить резюме с требованиями

- **Переменные:** `policy.*`, `profession.name`, `resume.experience`, `resume.skills`, `resume.achievements`, `vacancy.requirements`
- **Формат ответа:** json — `{ items: [{requirementId, status: confirmed\|unclear\|missing, evidence, advice}] }`
- **По умолчанию:** длина ответа 4000 токенов, бюджет контекста 32000 токенов, потоковый вывод: нет
- **Правило:** evidence — ссылка на конкретный фрагмент резюме. Общий процент соответствия не запрашивается и не показывается: он не отражает вероятность приглашения.

### `questions.generate` — Вероятные вопросы для подготовки

- **Переменные:** `policy.*`, `profession.*`, `prep.weakSpots`, `vacancy.requirements`, `resume.experience`, `user.experienceYears`
- **Формат ответа:** json — `{ questions: [{id, topic, text, why, guidance}] }`
- **По умолчанию:** длина ответа 4000 токенов, бюджет контекста 32000 токенов, потоковый вывод: нет
- **Правило:** Формулировка результата — «вероятные вопросы», без обещания, что спросят именно их.

### `answer.feedback` — Обратная связь на ответ пользователя

- **Переменные:** `policy.*`, `prep.questions`, `prep.answers`, `profession.name`
- **Формат ответа:** json — `{ strong: string[], gaps: string[], rewrite: string }`
- **По умолчанию:** длина ответа 1500 токенов, бюджет контекста 16000 токенов, потоковый вывод: нет
- **Правило:** Оценка ответа, а не человека. Без баллов и рейтингов.

### `interview.turn` — Реплика интервьюера в тренировке

- **Переменные:** `policy.*`, `session.mode`, `session.stage`, `session.turns`, `session.turnsSummary`, `session.askedTopics`, `prep.questions`, `prep.weakSpots`, `profession.name`
- **Формат ответа:** text — `одна реплика интервьюера`
- **По умолчанию:** длина ответа 1200 токенов, бюджет контекста 24000 токенов, потоковый вывод: да
- **Правило:** Модель ведёт интервью, а не оценивает вслух. Оценка выдаётся только в interview.summary.

### `interview.summary` — Итог тренировочного интервью

- **Переменные:** `policy.*`, `session.turns`, `session.turnsSummary`, `prep.weakSpots`, `profession.name`
- **Формат ответа:** json — `{ strong: string[], repeat: string[], advice: string[] }`
- **По умолчанию:** длина ответа 2000 токенов, бюджет контекста 32000 токенов, потоковый вывод: нет
- **Правило:** Опирается на реальные реплики сессии, а не на общие рекомендации.

### `prep.card` — Карточка подготовки к интервью

- **Переменные:** `policy.*`, `profession.name`, `prep.weakSpots`, `prep.questions`, `prep.answers`, `vacancy.requirements`, `resume.experience`
- **Формат ответа:** json — `{ opening: string, strongPoints: string[], risky: [{topic, howToAnswer}], askThem: string[], reminders: string[] }`
- **По умолчанию:** длина ответа 2500 токенов, бюджет контекста 24000 токенов, потоковый вывод: нет
- **Правило:** Краткая шпаргалка, которую человек читает перед разговором. Опирается на его собственные ответы: формулировки не выдумываются за него. Открывается на телефоне или втором экране и не требует чтения экрана и записи звука.

### `screen.extract` — Выделить вопрос из текста экрана

- **Переменные:** `policy.*`, `screen.captureConsent`, `screen.text`, `screen.textDelta`, `screen.image`
- **Формат ответа:** json — `{ question: string\|null, confidence: 0..1, speakerGuess: interviewer\|candidate\|unknown }`
- **По умолчанию:** длина ответа 900 токенов, бюджет контекста 8000 токенов, потоковый вывод: нет
- **Правило:** При captureConsent=false задача не выполняется. Если вопрос не найден — question=null, и подсказка не запрашивается.

### `assistant.hint` — Подсказка во время согласованного интервью

- **Переменные:** `policy.maxWords`, `policy.language`, `screen.detectedQuestion`, `prep.weakSpots`, `resume.experience`, `resume.skills`, `vacancy.requirements`, `profession.name`, `session.askedTopics`
- **Формат ответа:** json — `{ direction: string, remind: string\|null, avoid: string\|null }`
- **По умолчанию:** длина ответа 1200 токенов, бюджет контекста 12000 токенов, потоковый вывод: да, предел 40 слов
- **Правило:** Направление ответа, а не готовый текст для зачитывания. Ограничение по длине жёсткое: длинную подсказку невозможно прочитать в разговоре.

## Провайдеры

Набор переменных одинаков для всех сервисов. Различается только способ их передачи.

| Провайдер | Где данные | Системная инструкция | Формат истории | Структурированный ответ | Поле длины | Изображения | Поток | Кэш префикса | Глубина рассуждения | Сверено |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **Anthropic Claude** (`anthropic`) | за рубежом | top_level_field | roles_user_assistant | output_config_format | `max_tokens` | да | да | explicit_breakpoints | adaptive_thinking_plus_effort | да |
| **OpenAI и совместимые** (`openai`) | за рубежом | message_role | roles_system_user_assistant | response_format_json_schema | `max_completion_tokens` | да | да | automatic_prefix | effort_parameter | **нет** |
| **Google Gemini** (`gemini`) | за рубежом | system_instruction_field | contents_parts | response_schema | `maxOutputTokens` | да | да | explicit_cached_content | thinking_config | **нет** |
| **Локальная или своя модель с совместимым интерфейсом** (`openai_compatible`) | у себя | message_role | roles_system_user_assistant | best_effort_instruction | `max_tokens` | нет | да | none | none | **нет** |
| **YandexGPT** (`yandex`) | РФ | message_role | roles_with_text_field | best_effort_instruction | `completionOptions.maxTokens` | нет | да | none | none | **нет** |
| **GigaChat** (`gigachat`) | РФ | message_role | roles_system_user_assistant | best_effort_instruction | `max_tokens` | нет | да | none | none | **нет** |
| **Заглушка без сети** (`mock`) | — | top_level_field | roles_user_assistant | native | `max_tokens` | да | нет | none | none | да |

Столбец «Сверено» означает, что форма запроса проверена по актуальной документации.
Для остальных сервисов адаптер написан по общеизвестной схеме интерфейса и требует
проверки перед боевым запуском.

### Anthropic Claude

- Системная инструкция — отдельное поле system, а не роль в messages.
- Глубина рассуждения: thinking {type:"adaptive"} и output_config.effort (low…max).
- Предзаполнение ответа ассистента на текущих моделях не поддерживается — формат ответа задаётся структурированным выводом или инструкцией.
- Кэширование префикса задаётся точками cache_control; порядок рендера tools → system → messages.
- Для длинных ответов используется потоковый режим.

### OpenAI и совместимые

- Системная инструкция передаётся первым сообщением с ролью system.
- Название поля для ограничения длины отличается между версиями интерфейса — сверить перед запуском.
- Изображения передаются частями content с типом изображения.

### Google Gemini

- История называется contents, каждое сообщение состоит из parts.
- Роль ассистента называется model, а не assistant.
- Системная инструкция — отдельное поле, а не сообщение.

### Локальная или своя модель с совместимым интерфейсом

- Строгий JSON-режим чаще всего отсутствует: ответ приходится разбирать защищённо.
- Изображения обычно не поддерживаются — режим чтения экрана переключается на текстовый.
- Контекст меньше облачных моделей: бюджет усечения задаётся жёстче.

### YandexGPT

- Модель задаётся строкой modelUri вида gpt://<каталог>/<модель>.
- В сообщении поле text, а не content — общий адаптер не подходит.
- Обработка идёт внутри РФ: подходит для данных с персональными данными.
- Изображения не поддерживаются — режим чтения экрана переключается на текстовый.

### GigaChat

- Интерфейс совместим с форматом OpenAI, поэтому используется тот же адаптер.
- Токен доступа обменивается на ключ авторизации отдельным запросом и живёт ограниченное время: обновление токена в прототипе не реализовано.
- Обработка идёт внутри РФ: подходит для данных с персональными данными.

### Заглушка без сети

- Возвращает фиксированные ответы. Используется в прототипе и в тестах.
- Ни одного сетевого запроса не выполняет.
