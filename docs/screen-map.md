# Карта экранов и переходов

Навигация построена на hash-маршрутах, поэтому кнопка «Назад» в браузере работает.
Неизвестный маршрут безопасно возвращает на «Обзор».

## Публичная часть

| Маршрут | Экран | Переходы |
| --- | --- | --- |
| `#/start` | Начальная страница | «Открыть демо» → `#/onboarding`; «Экран входа» → `#/auth/login` |
| `#/auth/login` | Вход (заглушка) | `#/auth/register`, `#/auth/reset`, `#/onboarding` |
| `#/auth/register` | Регистрация (заглушка) | `#/auth/login`, `#/onboarding` |
| `#/auth/reset` | Восстановление доступа (заглушка) | `#/auth/login`, `#/onboarding` |
| `#/onboarding` | Выбор старта | «Создать резюме» → `#/resume/new`; «У меня есть резюме» → `#/resume/upload`; «Посмотреть пример» → заполненное демо и `#/overview` |

## Рабочий кабинет

Боковая навигация — семь разделов:

| Раздел | Маршрут |
| --- | --- |
| Обзор | `#/overview` |
| Мои резюме | `#/resumes` |
| Вакансии и подготовка | `#/vacancies` |
| Тренировочные интервью | `#/interviews` |
| Помощник на собеседовании | `#/assistant` |
| Тарифы и лимиты | `#/plans` |
| Настройки и данные | `#/settings` |

Дополнительно: `#/history` — история сеанса (ссылка внизу боковой навигации и с «Обзора»).

## Резюме

| Маршрут | Экран | Переходы |
| --- | --- | --- |
| `#/resumes` | Список версий резюме | открыть, переименовать, удалить (с подтверждением) |
| `#/resume/new` | Мастер: профессия → опыт → навыки → образование → предпросмотр | «Собрать резюме» → демонстрационное ожидание → предпросмотр → «Сохранить и использовать» → `#/vacancy/new` |
| `#/resume/upload` | Загрузка файла и образец разбора | «Показать пример анализа» → отчёт; «Сохранить как версию» → `#/resumes` |
| `#/resume/<id>` | Карточка версии | «Внести правку» (повышает версию), «Использовать для подготовки» → `#/vacancy/new` |

## Подготовка

| Маршрут | Экран | Переходы |
| --- | --- | --- |
| `#/vacancies` | Список подготовок | сопоставление, вопросы, удаление |
| `#/vacancy/new` | Добавление вакансии | «Создать подготовку» → `#/prep/<id>/match` |
| `#/prep/<id>/match` | Сопоставление требований | «Улучшить резюме» → `#/resumes`; «Перейти к вопросам» → `#/prep/<id>/questions`; «Изменить исходники» → диалог |
| `#/prep/<id>/questions` | Вопросы, ответы, фильтры | «Начать пробное интервью» → `#/prep/<id>/interview` |
| `#/prep/<id>/interview` | Текстовое интервью и итог | «Попробовать голосом» → `#/prep/<id>/voice` |
| `#/prep/<id>/voice` | Голосовая симуляция и итог | возврат в подготовку |
| `#/interviews` | Выбор подготовки и формата тренировки | чат или голос |

Одна подготовка связывает версию резюме, вакансию, сопоставление, вопросы и интервью.
Выбранная подготовка показана в шапке рабочей области, там же — кнопка «Заменить исходники».

## Связь данных и устаревание

```
резюме (версия N) ─┐
                   ├─> подготовка ─> сопоставление ─> вопросы ─> интервью ─> итог
вакансия (версия M)┘
```

Если после демонстрационного анализа изменить резюме или вакансию (правка, замена или
удаление исходника), подготовка помечается как относящаяся к предыдущей версии:
на «Обзоре», в списке и на экранах подготовки появляется предупреждение и кнопка
«Пересобрать демо». Старый отчёт не выдаётся за новый.

## Служебные элементы

- Шапка рабочей области: контекст подготовки, метка «Демо — ИИ и платежи не подключены»,
  переключение темы, кнопка меню на мобильных.
- Панель «Состояния демо» (правый нижний угол, сворачивается): сценарий
  пусто / заполнено / загрузка / ошибка / лимит, демо-тариф, сброс демо.
- Диалоги: закрываются по Escape, клику вне окна и кнопке; фокус удерживается внутри окна.
