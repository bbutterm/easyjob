# Живое интервью: исследование и семь итераций

Цель: сделать голосовую тренировку и живой контур быстрыми и правильными на границах
текста — как режется поток модели на фразы для синтеза, как режется распознанная речь для
модели, чем озвучивать, как не терять фразы при прерывании. Всё измерено бенчмарком
`npm run bench:live` (`tools/live-bench.js`, корпус `tests/fixtures/segmentation-ru.json`)
без сети: поток модели 120 знаков/с, синтез 250 мс на запрос, речь 15 знаков/с.

## Исследование: чем озвучивать

| Вариант | Веса и лицензия | Русский | Где работает | Решение |
| --- | --- | --- | --- | --- |
| Web Speech API (speechSynthesis) | встроен в браузер, без сети и ключей | системные голоса (Windows, macOS, Android есть; Linux зависит от системы) | клиент | **встроенный вариант в репозитории**: `shared/tts/index.js`, провайдер `browser` |
| Piper (piper1-gpl) | GPL-3.0 (прежний rhasspy/piper MIT в архиве); голоса ru_RU: irina, dmitri, denis, ruslan | да | CPU на сервере, HTTP `POST {text}` → WAV | **серверный вариант по умолчанию**: `TTS_PROVIDER=piper_http` |
| Kokoro-82M (Kokoro-FastAPI) | Apache-2.0 | нет русского | сервер, OpenAI-совместимый `/v1/audio/speech` | подключается как `openai_compatible` для английского |
| Silero TTS | модели CC BY-NC-SA | хороший русский | сервер | не для коммерческого продукта, не подключён |
| Fish Speech, XTTS-v2 | веса некоммерческие | да | GPU | не подключены |
| Облачные синтезаторы | закрытые | да | внешний API | подключаются как `openai_compatible`, ключ на сервере |

Итог: два пути. Встроенный — голос браузера, работает сразу и без сервера. Серверный —
`POST /api/tts/speak` к Piper или любому OpenAI-совместимому сервису, ключ и адрес только на
сервере (`.env.example`, `docs/stt.md`). Заглушка `mock` даёт тишину нужной длительности с
пометкой, чтобы конвейер и тесты работали без звука.

## Что не измерено

- Качество голосов и естественность фраз: без настоящего синтезатора в песочнице только
  тишина нужной длительности. Web Speech в headless Chromium без голосов.
- Длина и темп реплик настоящей модели в голосовом режиме: правило в запросе есть, ответ
  провайдера без ключа не измерялся.
- Задержка whisper.cpp и Piper на сервере владельца: модель бенчмарка берёт 250 мс на
  запрос синтеза; на CPU Piper даёт порядка 0,1–0,3 с на фразу, это надо подтвердить.

## Как включить

- Встроенный вариант: ничего; на экране голосовой тренировки выбрать «В браузере».
- Сервер: `TTS_PROVIDER=piper_http`, `TTS_ENDPOINT=http://127.0.0.1:5000/`, голос
  `TTS_VOICE=ru_RU-irina-medium`; запуск `python3 -m piper.http_server -m ru_RU-irina-medium.onnx`.
  Или `TTS_PROVIDER=openai_compatible` с `TTS_ENDPOINT=…/v1/audio/speech`, `TTS_MODEL`, `TTS_VOICE`,
  `TTS_API_KEY`.
- Распознавание: STT-виджет, провайдер «Сервер Easyjob» при `STT_PROVIDER=whisper_cpp` на сервере.
