# Карьерный помощник — кликабельный макет

Демонстрационный frontend-прототип русскоязычного сервиса подготовки к поиску работы и
собеседованиям. Это **макет интерфейса**, а не работающий продукт.

> **Демо — ИИ и платежи не подключены.** Настоящего ИИ, backend, авторизации, платежей,
> чтения документов и скачиваемого помощника здесь нет. Их результаты имитируются
> заранее подготовленными и явно помеченными демонстрационными данными.

## Запуск

Сборщик, npm-зависимости и сеть не нужны.

```
# вариант 1 — просто открыть файл в браузере
open index.html        # macOS
xdg-open index.html    # Linux

# вариант 2 — локальный сервер, если браузер ограничивает file://
python3 -m http.server 8000
# затем http://localhost:8000/
```

`index.html` в корне — автономная сборка: весь CSS и JavaScript встроены внутрь одного файла.
Его можно переслать одним вложением, и он откроется без интернета.

## Структура

```
index.html          автономная сборка (открывать этот файл)
build.js            сборка index.html из src/ — node build.js
src/                исходники
  index.html        разметка-оболочка со ссылками на отдельные файлы
  styles.css        токены оформления и компоненты
  data.js           единый комплект демонстрационных данных
  state.js          состояние макета и правила хранения
  ui.js             диалоги, уведомления, поля, экранирование
  screens-core.js   вход, обзор, резюме, вакансии
  screens-prep.js   сопоставление, вопросы, интервью, помощник, тарифы, настройки
  app.js            hash-маршрутизация и обработка действий
tests/check.js      сквозная проверка в браузере (Playwright)
docs/screen-map.md  карта экранов и переходов
docs/stubs.md       перечень заглушек
docs/test-report.md отчёт о выполненных проверках
docs/screenshots/   снимки экранов desktop и mobile
```

Работать с кодом удобнее в `src/`. После правок нужно пересобрать корневой файл:

```
node build.js
```

Каталог `src/` тоже открывается напрямую (`src/index.html`) — файлы подключаются
обычными тегами `<link>` и `<script>`, без модулей и без сборщика.

## Что можно пройти в макете

1. Начальная страница → выбор сценария → мастер резюме → предпросмотр → вакансия →
   сопоставление → вопросы → текстовое интервью → итог.
2. Загрузка готового резюме с устройства → объяснение ограничений → образец разбора →
   принятие и отклонение предложений.
3. Изменение резюме или вакансии → прежний отчёт помечается как относящийся к
   предыдущей версии → пересборка демо.
4. Голосовое интервью: состояния «Слушаю», «Готовлю ответ», «Отвечаю», «Пауза»,
   «Связь потеряна», завершение — без обращения к микрофону.
5. Помощник на собеседовании: выбор подготовки, заглушка скачивания, демо-статусы
   подключения, примеры подсказок, предупреждение о правилах и согласии участников.
6. Тарифы: переключение демо-уровня, блокировка разделов с объяснением, заглушка оплаты,
   состояние исчерпанного лимита.
7. Пустые состояния, ошибки форм, диалоги подтверждения, сброс демо, тёмная тема.

Панель «Состояния демо» в правом нижнем углу переключает сценарии
(пусто / заполнено / загрузка / ошибка / лимит) и демо-тариф. Она свёрнута по умолчанию
и не является частью продукта.

## Ограничения прототипа

- Настоящего ИИ нет. Все «результаты анализа» — фиксированные образцы из `src/data.js`.
  Они одинаковы для всех и **не подстраиваются** под введённый текст.
- Загруженный файл не читается, не разбирается и не покидает браузер. Поддержка PDF и
  DOCX не реализована.
- Получение вакансии по ссылке не реализовано: макет не выполняет сетевых запросов.
- Авторизации нет. Пароли не собираются, письма не отправляются.
- Платежей нет. Цены и лимиты не определены, названия тарифов рабочие.
- Скачиваемый помощник не существует: формат файла, поддерживаемые ОС, способ установки
  и протокол соединения не определены. Кнопка «Скачать помощник» открывает объяснение и
  не отдаёт никакой файл.
- Звук и экран не захватываются, микрофон не запрашивается, синтеза речи нет.
- Введённые данные хранятся только в памяти вкладки и сбрасываются после перезагрузки.
  В `localStorage` сохраняются исключительно тема, выбранный демо-сценарий, демо-тариф и
  состояние демо-панели — ни резюме, ни файлов, ни токенов, ни паролей.
- Внешние шрифты, CDN, аналитика и AI SDK не подключаются.
- Тексты о приватности — черновик формулировок, а не юридически готовая политика.
- Все персоны, компании и вакансии вымышлены и созданы для демонстрации.

## Проверка

```
node tests/check.js
```

Скрипту нужен установленный `playwright` с Chromium. Он открывает `index.html` в браузере,
проходит основные сценарии, проверяет отсутствие сторонних сетевых запросов и ошибок в
консоли и сохраняет скриншоты. Результат последнего прогона — в `docs/test-report.md`.
